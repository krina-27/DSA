# Array DSA — Quick Terminology

| Term | Meaning | Example |
|---|---|---|
| Increasing | Strictly smaller to larger | `[1, 2, 3, 4]` |
| Non-decreasing | Smaller to larger; duplicates allowed | `[1, 2, 2, 4]` |
| Decreasing | Strictly larger to smaller | `[4, 3, 2, 1]` |
| Non-increasing | Larger to smaller; duplicates allowed | `[4, 4, 2, 1]` |
| Subarray | Contiguous elements | `[2, 3]` from `[1, 2, 3, 4]` |
| In-place | Modify the original array without a proportional extra array | Reverse an array |
